# 07 · Picture Quiz (No Reading)

**Band:** Very Young (2–5) · **Type:** Activity (quiz) · **Time:** 3–5 min · **Runtime:** one HTML file

## 1 · What it is
Six questions, each with **one picture answer and one clearly wrong decoy**, no text options at
all. The adult reads the question ("Which one is the duck?"); the child points or taps. There is
no score, no timer, no losing — only "yes!" and "try again". It is the gentlest possible
comprehension check for a pre-literate child. (Picture-choice assessment used by Khan Academy
Kids and preschool speech-screeners.)

## 2 · Goals
- The child **shows understanding** of 4–6 spoken words by choosing a picture.
- The child **hears each target word** in a question, not in isolation.
- The tutor gets a quick, no-pressure read of which words are solid and which need replaying.

## 3 · Interaction flow
1. Splash → "Let's go!".
2. **Warm-up question** — one very easy one so the first tap is always a win.
3. **Five more** — two big pictures each, the decoy visibly different (different animal/hue).
4. **Wrong tap** — the picture wobbles, says "nearly!", and stays tappable; no penalty.
5. **Finish** — every picture the child found lines up in a little parade + family line.

## 4 · Tutor notes
- Read the question aloud exactly as written; the screen never asks the child to read.
- Correct answer position must alternate — never the same spot twice in a row.
- If the child taps the decoy on purpose to be funny, play along and name both pictures.
- The whole quiz can be replayed with the same six words all week.
