# 15 · Memory Pairs 🧠

**Band:** Young (5–9) · **Type:** Game (screen) · **Time:** 6–9 min · **Runtime:** one HTML file

## 1 · What it is
Twelve cards face-down in a grid; the child turns two and finds a matching pair — word to
picture, or word to meaning. Working memory is the bottleneck for everything else in a lesson,
and this loads it gently: hold a card's position while doing something else. Matching word to
picture forces the *meaning*, not just the shape of the word. (Classic memory pairs; used from
ABCmouse to Twinkl.)

## 2 · Goals
- The child **finds 6 pairs** and says each word aloud as it is turned.
- The child **holds positions** in memory across several turns (the real skill).
- The tutor hears **every target word spoken** at least twice.

## 3 · How a round runs
1. Splash → "Let's go!".
2. Twelve cards in a 3×4 grid; first card turns for free (teaches the mechanic).
3. Turn two; a match locks with a chime and the word is spoken; a miss turns both back gently.
4. Every flip names its card aloud — the game is listening practice too.
5. Every pair found = a star; a "help me" button reveals one card for the youngest players.
6. Finish: the six pairs line up + "Great memory!" + one replay with a shuffled grid.

## 4 · Tutor & room notes
- Six pairs is the ceiling; more becomes a memory marathon, not a game.
- Every pair must be unambiguous — one word, one picture.
- Allowed to be wrong: a miss costs nothing but the turn.
- Say the word when a card turns, so the game is heard as well as played.
