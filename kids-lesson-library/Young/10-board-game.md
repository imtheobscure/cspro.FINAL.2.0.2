# 10 · Board Game

**Band:** Young (6–12) · **Type:** Activity (printable board game) · **Time:** 15–25 min · **Runtime:** one HTML file with print stylesheet

## 1 · What it is
A board of 18–24 squares in a loop, each square holding one task — say the word, spell it, use
it in a sentence, act it out. Two counters and a die; on screen the die and counters are animated,
and the same board prints in one minute for the no-screen version. The rule is a "no-lose" rule:
the game ends when **both** counters finish, so the child is never left behind. (Classic ESL
board games; differentiation-safe by design.)

## 2 · Goals
- The child **completes 10+ language tasks** in one game without it feeling like drilling.
- The child **reads the square tasks** (5+ readers) or hears them (younger readers).
- The child **uses the target words in a sentence** at least three times.
- The tutor has a printable board for the class drawer.

## 3 · Interaction flow
1. Splash → "Let's go!".
2. **Print or play** — choose the screen board or Print (A4 landscape).
3. **Roll** — animated die; the counter hops; the square's task is shown big.
4. **Do the task** — speak/spell/act; the tutor taps ✓ or "again later".
5. **Special squares** (3–4): "trade places", "say it twice", "free high five".
6. **Both counters finish** → the board fireworks + "You both won!" + family note.

## 4 · Tutor notes
- The no-lose rule is the point; never let one counter finish first.
- Reading the square aloud for the child is allowed at any age; the task is the language, not the reading.
- Park any task the child found hard as the week's home card.
- Print in greyscale; counters can be coins, squares can be drawn.
